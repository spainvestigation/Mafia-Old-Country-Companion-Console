## 🗂️ What Exactly Is Inside

Each module was designed with a single guiding principle: **your save file is yours, and you should understand it completely.**

## 🛡️ Safety Philosophy

Three rules govern every line of code in this repository:

1. **Backup before touching anything.** Snapshots are automatic, not optional.
2. **Reversibility over speed.** Any change can be undone with a single action.
3. **Local only.** No network calls modify your game. No telemetry. No accounts.

If a routine cannot guarantee all three, it doesn't ship.

## 📚 Frequently Explored Topics

**Can I reverse a change I made three days ago?**
Yes. Every adjustment is stored in the snapshot timeline, and you can roll back to any point.

No. The toolkit operates purely on local save data. Achievements synced to your platform account remain untouched.

Yes, in portable mode. Copy the folder, and your configuration and snapshots travel with it.

**Is there a way to contribute a translation?**
Absolutely — localization files are plain text and endlessly welcoming to new contributors.

**What happens if I close the tool mid-operation?**
The snapshot system protects you. On next launch, the companion detects the incomplete operation and offers to restore the last stable state.

## 🧪 Technical Design Notes

The Save Alchemist is built around a **layered file-access architecture**:

- A **read layer** that interprets save structures without writing anything.
- A **diff layer** that calculates exactly what would change before it changes.
- A **write layer** that applies changes atomically, never partially.
- A **journal layer** that records every operation into the snapshot timeline.

This separation means the tool can always answer the question: *what would happen if I pressed this button?* — before you press it.
